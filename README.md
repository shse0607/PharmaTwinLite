# PharmaTwinLite
A manufacturing-inspired digital twin simulator built in C++. 

**Current Scope**
Version 1 includes:

Tank
Fill Valve
Drain Valve
Level Sensor
Overflow Alarm

**Purpose**
The project is designed to combine:

Manufacturing
Validation
Process Simulation
Software Engineering

**Future Features**
Temperature Control
Pumps
Alarm Manager
Batch Recipes
State Machines
Automated Validation Testing
